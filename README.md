# Advanced Telegram Card Bot
Foundation + 13 rarity tiers + packs + pity + daily + owner basics.

Setup: copy .env.example to .env, fill values, install requirements, run `python seed.py`, then `python main.py`.

Commands: /start /profile /cards /daily /packs /open_<id> /owner /owner_stats /owner_user <id> /owner_give <id> <coins>
